🐰 ふんわり英文法 🎀

〜 関係代名詞に隠れた「仮定法」 〜

✨

📖 ifがないのに仮定法？

「もし〜なら」と言いたいとき、普通は If を使うよね。
でも実は、関係代名詞（who や which）のカタマリが、「もし〜な人（モノ）だったら…」という仮定法の意味を持つことがあるんです！

💡 ポイント

文のうしろに would や could (〜だろうに) があったら、「あれ？これ仮定法かも？」と疑ってみてね！

🐻

🔍 いっしょに見てみよう！

1 人を表すパターン (who)

A person who knew the truth would not say such a thing.

訳：真実を知っている人（もしそういう人がいれば）、そんなことは言わないだろうに。

＝ If there were a person who knew the truth, they would not say...

2 モノを表すパターン (which)

An electronic dictionary which was lighter would be more convenient.

訳：もっと軽い電子辞書（もしそういう辞書があれば）、もっと便利だろうに。

＝ If you had an electronic dictionary which was lighter, it would be...

📝

ミニクイズに挑戦！

空欄に当てはまる英単語を入力してね♪

「本当の友達なら、君を見捨てないだろう。」

A true friend a true friend not desert you.
🎉

💡 正解は... A true friend who was a true friend would not desert you.
